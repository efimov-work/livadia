# livadia

Сайт сити-курорта «Новая Ливадия» в Ялте. Визуальная система, характеристики и контакты основаны на клиентской презентации. Фотографии загружены локально с официальных сайтов проекта и девелопера.

## Стек

Next.js 16.4.5, React 19.3.0, TypeScript 5.9.3, App Router и CSS без UI-библиотек. Шрифты Manrope и Prata хранятся локально.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Проверка и производственная сборка:

```bash
npm run typecheck
npm run build
```

Статическая версия и тесты:

```bash
NEXT_PUBLIC_BASE_PATH=/livadia NEXT_PUBLIC_SITE_URL=https://efimov-work.github.io SITE_NOINDEX=0 npm run export
npm test
```

Результат экспорта находится в `out/`.

## GitHub Pages

Публикация использует отдельную ветку `gh-pages`:

```bash
npm run pages
```

Скрипт определяет адрес репозитория из `origin`, собирает сайт с базовым путём и отправляет содержимое `out/` в `gh-pages`. В настройках GitHub Pages нужно выбрать эту ветку и корневой каталог.

## SEO

В `src/lib/seo.ts` собраны метаданные, canonical, Open Graph, Twitter Card и JSON-LD. Предусмотрены `sitemap.xml`, `robots.txt` с правилами для Яндекса, манифест и локальная иконка. Без заданного домена индексация отключена.

## Заявки

Форма формирует письмо на официальный адрес `info@newlivadia.ru` в почтовом приложении пользователя. Сайт не сохраняет введённые данные и не требует серверного API. Телефонные ссылки ведут на `8 800 533 87 52`.

## Структура

```text
src/app/          страница, стили и SEO-маршруты
src/components/   шапка, инфраструктура, форма, анимации и подвал
src/lib/          контент, контакты, пути и метаданные
public/assets/    локальные изображения
scripts/          статический экспорт и публикация Pages
tests/            проверки собранного сайта
```
